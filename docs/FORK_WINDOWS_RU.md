# Rustcord для Windows · сборка форка

## Проверка

1. Зайдите в голосовой канал с участником, который показывает стрим со звуком через Discord. Нажмите **Watch stream**, затем ПКМ по самой плитке стрима. Проверьте **Volume** от 0 до 200% и **Mute stream**. Звук стрима должен меняться, а голос участника — идти с прежней громкостью. **VolumeBooster** продолжает управлять голосом.
2. Нажмите стрелку рядом с микрофоном слева внизу и выберите **Noise suppression → RNNoise**. Ту же настройку можно менять в **Voice & Video**. В звонке сравните **Off** и **RNNoise** на фоне клавиатуры или вентилятора. Переключение применяется сразу, значение сохраняется локально.
3. Откройте **Share your screen → Screens**, выберите монитор и отметьте **Desktop Duplication (monitor without a border)**. Этот режим работает с целым монитором на Windows 10/11. Для отдельного окна, повёрнутого дисплея или проблемного GPU оставьте стандартный режим Windows Graphics Capture. Некоторые отдельные системные курсоры в Desktop Duplication могут не передаваться. Проверьте с собеседником правильный монитор, отсутствие рамки и остановку захвата.
4. Закройте официальный клиент Discord, если он запущен. В Rustcord откройте **Settings → Registered Games** и включите **Show PulseSync activity**. В PulseSync/Yandex Music включите Discord RPC со стандартным Application ID и запустите трек. В своём профиле в Rustcord должны появиться название и исполнитель. Если PulseSync уже был открыт, ему может потребоваться повторно подключиться или перезапуститься. Настройка показывает активность локально и очищает её при остановке/отключении. Она не публикует музыку в Discord.

Отдельного переключателя передачи звука собственного стрима в этих изменениях нет.

## Обновления

Эта сборка читает подписанный манифест из [релизов форка](https://github.com/blueredtronce-rgb/Rustcord/releases). Старый EXE использует ключ и репозиторий upstream. Для перехода один раз запустите установщик форка поверх Rustcord после выхода через значок в трее. Переустановка с тем же профилем сохраняет настройки. Установленные копии используют подписанные обновления, portable-копии показывают уведомление.

У форка отдельный Ed25519-ключ и каталог staging. Закрытый ключ хранится в GitHub Actions Secrets, в репозитории лежит только публичный ключ. Контроль SHA-256 установщика и проверку манифеста updater выполняет перед применением.
